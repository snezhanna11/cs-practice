working directory- это рабочая папка, в которой создают и меняют файлы
staging area- индекс, это "черновик", куда добавляют файлы командой git add, чтобы подготовить их к сохранению
commit- сохранение файлов в истории проекта

Git- программа, с помощью которой отслеживаются изменения на компьютере, а GitHub- это сайт для хранения проекта в интернете

git init- создает новый репозиторий

git status- показывает текущее состояние

git add- добавляет файлы в индекс

git commit- сохраняет изменения

git log- показывает историю всех коммитов

git diff- показывает разницу между рабочей папкой и индексом

git diff --staged- показывает разницу между индексом и последним коммитом

Ветки и слияние:

Ветка- отдельный черновик проекта, где можно безопасно экспериментировать, не ломая основную работу

При создании нового коммита в ветке все сохранения уходят туда, а главная ветка остается неизменной

Слияние (merge)- объединение изменений из рабочей ветки обратно в главную, чтобы они стали частью общего проекта
