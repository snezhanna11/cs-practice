git log - историю коммитов. Нужен для просмотра общей истории проекта
git show - показывает подробную информацию по "конкретному" коммиту вместе с полным списком изменений
git diff - сравнивает два состояния кода, показывая точечные изменения (что было удалено или добавлено) без вывода метаданных коммитов

git log -S'print' - находит все коммиты, в которых добавлялась или удалялась строка с текстом "print". Позволяет отследить историю изменения конкретной функции или команды в коде
git blame lab03/calc.py - выводит содержимое файла построчно, указывая для каждой строки хэш коммита, автора и время изменения. Показывает, кто и  когда написал каждую строчку кода

git restore lab03/calc.py - сбрасывает изменения в рабочей директории и возвращает файл к состоянию из последнего коммита. Все несохраненные правки при этом безвозвратно теряются

git restore --source=HEAD\~2 lab03/calc.py - подтягивает версию файла из указанного более раннего коммита, позволяя временно или постоянно вернуть более старый код, не переключая всю ветку целиком

git revert HEAD - создает новый коммит, который полностью аннулирует изменения последнего коммита. История проекта сохраняется линейной и безопасной для совместной работы, так как прошлая история не стирается, а дополняется отменяющим действием

Tag(Тэг) - это "закладка" на конкретный коммит. Он не двигается вперед при создании новых коммитов и служит для фиксациирелизов

Branch(Ветка) - указатель на коммит, который автоматически смещается вперед при создании новых коммитов в процессе разработки
